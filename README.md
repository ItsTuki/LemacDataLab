# 📱 LemacDataLab - App Móvil de Autorregistro y Seguimiento Personal

![Estado](https://img.shields.io/badge/Estado-MVP_Académico-blue)
![Plataforma](https://img.shields.io/badge/Plataforma-Android-green)
![Asignatura](https://img.shields.io/badge/Asignatura-DSY1105-orange)

Este proyecto es un Producto Mínimo Viable (MVP) académico desarrollado para la asignatura DSY1105 Desarrollo de Aplicaciones Móviles, en colaboración con el socio formador **Lemac DataLab**[cite: 1]. 

El objetivo principal es entregar un producto móvil orientado a que las personas usuarias puedan acceder a herramientas de registro, organización y seguimiento personal[cite: 1].

---

## 📖 ¿Qué hace el proyecto?

La aplicación consolida en un punto único, simple y accesible desde el dispositivo móvil, los registros y recursos de autocuidado que normalmente se encuentran fragmentados en notas y aplicaciones separadas[cite: 1]. 

La aplicación se centra en cuatro ámbitos principales:
1. **Neurodesarrollo**[cite: 1].
2. **Habilidades DBT** (terapia dialéctico-conductual)[cite: 1].
3. **Estado de ánimo**[cite: 1].
4. **Adicciones**[cite: 1].

A través de esta plataforma, el usuario puede iniciar y completar registros breves, consultar herramientas pertinentes, revisar antecedentes previos y mantener una visión ordenada de su propia actividad[cite: 1].

> **⚠️ Importante:** Este MVP académico utiliza exclusivamente datos ficticios o sintéticos[cite: 1]. No sustituye la atención profesional, no emite diagnósticos, no indica tratamientos ni funciona como un servicio de urgencia[cite: 1].

## 🎯 ¿Para quién va dirigido?

El sistema define los siguientes perfiles involucrados[cite: 1]:

- **Usuario final:** Persona que necesita realizar, de manera rápida y repetible, registros de autorreporte diarios o frente a eventos específicos[cite: 1].
- **Responsable de contenidos:** Encargado de administrar catálogos, textos educativos, ejercicios y parámetros generales[cite: 1].
- **Administración/operación:** Encargado de gestionar los accesos de prueba, la disponibilidad del servicio y el soporte funcional[cite: 1].
- **Equipo académico de desarrollo:** Administradores técnicos del MVP[cite: 1].

## ✨ Características Principales por Módulo

- 🧠 **Módulo de Neurodesarrollo:** Permite registrar rutinas, organización de tareas, situaciones de sobrecarga o autorregulación y las estrategias utilizadas por el usuario[cite: 1].
- 🧘 **Módulo DBT:** Funciona como un registro tipo diario de habilidades practicadas, emociones o situaciones asociadas y la utilidad percibida, permitiendo además consultar contenidos psicoeducativos[cite: 1].
- 📊 **Módulo de Ánimo:** Facilita la realización de check-ins de estado de ánimo, evaluando intensidad y contexto, con la opción de añadir una nota[cite: 1].
- 🛑 **Módulo de Adicciones:** Permite registrar impulsos (craving), desencadenantes, acciones protectoras y el cumplimiento de objetivos personales de prueba[cite: 1].

**Funciones Transversales:**
- Revisión de historial y consulta de resúmenes de uso[cite: 1].
- Configuración de recordatorios discretos mediante notificaciones[cite: 1].
- Corrección o eliminación de los propios registros por parte del usuario[cite: 1].
- Persistencia local de registros ante interrupciones de conectividad y posterior sincronización[cite: 1].

## 🛠️ Especificaciones Técnicas

- **Plataforma Principal:** Desarrollo enfocado inicialmente en dispositivos Android, adaptándose a distintos tamaños de pantalla[cite: 1].
- **Arquitectura:** Separación clara entre la interfaz móvil y los datos/servicios, mediante conexión a una API de prueba[cite: 1].
- **Integraciones:** Servicios de autenticación para usuarios de prueba, catálogos/contenidos, almacenamiento/sincronización y un motor de notificaciones[cite: 1].
- **Privacidad y Accesibilidad:** Minimización de datos desde el diseño, controles claros, tipografía legible y contraste adecuado[cite: 1].
